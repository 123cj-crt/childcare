## 三、你必须在微信开发者工具里做的 3 件事（不做功能不可用）

### 1. 上传云函数
右键 `cloudfunctions` 下**每个**目录 → 「上传并部署：云端安装依赖（不上传 node_modules）」：
- `reservation`
- `children`
- `attendance`
- `tweet-interaction`

### 2. 建云数据库集合
云开发控制台 → 数据库 → 新建集合，权限统一设为 **「所有用户可读，仅创建者可写」**：
- `reservations`
- `children`
- `attendance`
- `tweet_likes`
- `tweet_comments`

### 3. 发布体验版
开发者工具 → 上传代码（填版本号如 `1.0.2-exp`）→ 公众平台「版本管理」→ 把刚上传的设为**体验版** → 下载体验版二维码发给家长。

> 注意：体验成员扫码即可，无需备案；非体验成员仍需先加为体验成员（成员管理 → 体验成员）。
